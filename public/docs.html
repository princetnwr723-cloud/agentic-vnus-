How It Works — Architecture

The scheduler runs as a background daemon inside the Electron agent. On startup, it loads all saved schedules from ~/.vnus-agent/schedules.json and registers them with the node-cron engine. Commands from your website (create, update, delete, run-now) are received instantly via Realtime Database WebSocket — the agent acts on them immediately without any polling.

6 Trigger Types — Each Unique

Daily — Time-based
Runs every day at a specific time. Pick HH:MM and timezone. Example: every day at 9:00 AM IST check emails and summarize.
Interval — Repeating
Runs every N minutes. Set 30 min, 60 min, or any interval. Example: every 60 minutes backup active project to Desktop.
Cron Expression — Advanced
Full cron syntax for power users. 5-field expressions like 0 9 * * 1-5 — 9am weekdays only. Any pattern possible.
Condition — Smart Trigger
Only runs when a condition is met. Example: "if file 'report.csv' exists on Desktop then process it". Checked every 5 minutes.
File Watcher — Event-driven
Watches a folder for changes. Triggers the moment a file is added, modified, or renamed. Example: watch Downloads → auto-sort new files.
Startup — On Agent Start
Runs 5 seconds after agent launches. Example: open VS Code and Chrome every time you start your PC. Morning routine automation.

Important

Warnings & Limitations

Small Models Make Mistakes

On 8 GB RAM, agent uses 4B model. Handles simple tasks well but may misunderstand complex multi-step commands. Rephrase and retry if something fails.

No Undo for Destructive Actions

Agent can delete files and push code. No confirmation for low-risk operations. Verify your command before sending. Blocked commands prevent the most dangerous operations.

Internet Required for Setup Only

AI engine and model download once on first setup. After that, agent works fully offline. On slow connections, 19 GB model can take over an hour.

PC Performance During Inference

AI uses significant CPU/RAM while processing commands. PC may feel slower for 5–30 seconds. The 50% RAM rule reduces this impact.

CAPTCHA Cannot Be Bypassed

Websites showing CAPTCHA during automation block the agent. Financial institutions, government portals, heavily protected login pages may not work.

Email Uses Browser Automation

Email sending opens Gmail/Outlook in browser and uses the compose interface. Direct SMTP email is planned for a future update.

FAQ

Frequently Asked Questions

Does the agent work without internet?

Yes — after first setup, everything runs offline. Only network activity is the Realtime Database WebSocket to receive commands and send results — tiny amount of data.

Where does my data go?

Commands temporarily pass through Realtime Database to bridge browser and PC. AI processing happens entirely on your machine. Memory, skills, session history, tokens — stored locally, never transmitted anywhere.

How do I reconnect after disconnect?

Open the agent app — shows your connection code. Dashboard → Add Workspace → enter code. Your permanent code never changes on the same machine.

Can I use the agent on multiple PCs?

Yes — each PC gets its own connection code. Add as many workspaces as your plan allows. Each workspace runs independently with its own model and memory.

What if model download fails?

Agent shows specific error and Retry button. Your plan stays active. Check internet connection and available disk space — you need at least 2 GB more than the model size.

Does the scheduler keep running when browser is closed?

Yes — scheduler runs inside the Electron agent in your system tray. As long as the tray icon is visible, all scheduled tasks execute on time regardless of browser.

Can I create schedules from my phone?

Currently through the dashboard website on mobile browser. Native mobile app with full scheduler UI launches August 20, 2026.

Technical Reference

Architecture Deep Dive

Intelligence Layer (brain.js)

Builds system prompt combining persistent memory, available skills, and task-specific Chain-of-Thought reasoning instructions. Detects task type (coding / browser / files / reasoning) and routes to appropriate model. Responses parsed as structured JSON action sequences. Invalid output retries 3 times with clearer formatting instructions.

Memory Layer (memory.js)

Reads/writes ~/.vnus-agent/memory.json. User preferences, facts, corrections, session summaries — injected into every AI prompt automatically. Agent always has full context without you repeating yourself.

Skills Layer (skills.js)

After each successful task, checks if command matches a learnable pattern. If matched, saves skill file locally with trigger phrases, action templates, success counter. Failed skills auto-marked stale and regenerated from fresh AI planning.

Scheduler Layer (scheduler.js)

node-cron engine registers all schedules on startup. 6 trigger types handled independently — cron/daily/interval use node-cron, file triggers use fs.watch, conditions poll every 5 minutes, startup runs after 5 second delay. All schedule operations (create/update/delete/run-now) received via RTDB WebSocket instantly from website. History logged locally and synced to RTDB for dashboard display.

Command Listener (listener.js)

Firebase Realtime Database SSE (Server-Sent Events) WebSocket — zero polling. Commands arrive instantly via persistent connection. Rate limited to 20/minute per user. Ownership verified before execution. Skills synced to RTDB after every task so workspace dashboard shows learned skills in real time.

Action Execution Priority

1. Browser actions   — most reliable for web tasks
2. PC control        — native app interactions
3. File operations   — always reliable
4. Repository API    — requires access token
5. Shell commands    — most powerful, permission-gated

Installation

Installation Warnings — Windows, Mac & Linux

Agentic Vnus is not yet code-signed by Microsoft or Apple. This means your operating system will show a security warning during installation. This is completely normal — the app is safe. These warnings appear on any app that is not yet certified. Follow the steps below for your platform.

Windows — How to Install Past the "Don't Run" Warning

Windows SmartScreen Warning

"Windows protected your PC" or "Don't run" — this message appears because the app is not yet Microsoft-certified. The app is completely safe. This warning shows on all new, unsigned applications.

  • 1
    Download the setup file
    Download AgenticVnus-Setup-1.0.0.exe. If your browser shows a warning, click the download arrow and select "Keep" or "Keep anyway".
  • 2
    Double-click the .exe file
    A blue screen will appear saying "Windows protected your PC". Do not close it — this is expected behavior for unsigned apps.
  • 3
    Click "More info"
    At the bottom of the blue screen, click "More info". The app name and publisher will be shown.
  • 4
    Click "Run anyway"
    A "Run anyway" button will appear — click it. Installation will begin immediately.
  • 5
    Click "Yes" on the UAC prompt
    When asked "Do you want to allow this app to make changes to your device?" — click Yes. The installer will complete and Agentic Vnus will be ready.

If Chrome or Edge blocked the download — click the arrow next to the file in the download bar → select "Keep" or "Keep anyway" → then run the installer.

Mac — How to Open Past the "Cannot be Opened" Warning

macOS Gatekeeper Warning

"Agentic Vnus cannot be opened because it is from an unidentified developer" — this is macOS Gatekeeper protecting you from unsigned apps. The app is safe. It is not yet Apple-notarized.

  • 1
    Download the correct DMG for your Mac
    Intel Mac (2015–2020): AgenticVnus-1.0.0-x64.dmg — Apple Silicon Mac (M1/M2/M3/M4): AgenticVnus-1.0.0-arm64.dmg. Check your Mac by clicking the Apple menu → About This Mac.
  • 2
    Open the DMG and drag the app
    Open the downloaded DMG file → drag the Agentic Vnus icon into your Applications folder.
  • 3
    Right-click to open (Important — first time only)
    Go to Applications. Do not double-click Agentic Vnus. Instead, right-click → Open.
  • 4
    Click "Open" in the popup
    A warning dialog will appear — click "Open". You only need to do this once. After that, the app opens normally every time.
  • 5
    If there is no "Open" button
    Go to System Settings → Privacy & Security → scroll down → next to "Agentic Vnus was blocked" click "Open Anyway" → enter your password → Open.

Alternative method via Terminal: run sudo xattr -rd com.apple.quarantine /Applications/Agentic\ Vnus.app — then open normally by double-clicking.

Linux — How to Run the AppImage

AppImage Permission Required

On Linux, AppImage files are not executable by default. You need to grant execute permission manually before running.

  • 1
    Download the AppImage
    Download AgenticVnus-1.0.0.AppImage — it will be saved to your Downloads folder.
  • 2
    Grant execute permission
    Open Terminal and run: 
    chmod +x ~/Downloads/AgenticVnus-1.0.0.AppImage
  • 3
    Run the app
    ~/Downloads/AgenticVnus-1.0.0.AppImage
    Or in your file manager, double-click the file → select "Execute".
  • 4
    If you get a FUSE error
    sudo apt install libfuse2
# On Ubuntu 22.04 or later:
sudo apt install libfuse2t64
    Then run the AppImage again.
