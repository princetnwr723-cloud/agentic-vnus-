What is Agentic Vnus?

Agentic Vnus is a self-hosted AI agent that runs entirely on your PC. It connects your browser dashboard to an always-available AI that controls your machine — files, browser, terminal, GitHub, and more.

The agent learns from every interaction. It remembers your preferences, saves reusable skill patterns, understands your business context, and gets smarter with every session.

What you can do

⚡Control your PC with plain language›

Open apps, create files, run terminal commands, take screenshots, browse the web, interact with any application — all from your dashboard. Commands arrive in under 100ms via WebSocket.

"Create a Python script on Desktop that renames all photos by date"
"Open VS Code and push my changes to GitHub"
"Take a screenshot and send it to me"
🧬Set up Business DNA and become your AI executive›

Introduce your business once — 20 questions, 5 minutes. Your agent stores everything forever and operates as your dedicated AI CEO, CMO, CTO, CFO, or Sales Lead. Every command uses your business context. No other agent in the world does this.

👥Assemble agent teams for complex tasks›

Complex tasks automatically assemble a team of specialist agents — Research, Strategy, Marketing, Developer, Writer, Analyst, Sales, Editor. Each agent builds on the previous one's output. Results are far better than a single agent alone.

"Create a full marketing campaign for my SaaS launch"
→ Research Agent → Strategy Agent → Marketing Agent → Writer → Editor
⏰Automate tasks on a schedule›

Schedule any task with 6 trigger types — daily, interval, cron expression, condition, file watcher, or startup. Runs in the background even when your browser is closed. No other local AI agent has a visual scheduler.

🔀Connect API keys for complex task power›

Paste one API key from any of 10 providers — Anthropic, OpenRouter, OpenAI, Gemini, Groq, Mistral, Together AI, DeepSeek, Perplexity, or Cohere. Simple tasks always use local AI (free). Complex tasks automatically use your connected API. Keys are encrypted on your PC — never sent to any server.

🔗Integrate with GitHub, browser, and terminal›

Full GitHub REST API — read files, write commits, create PRs, manage issues. Stealth Playwright browser — navigate, click, fill forms, extract data. Terminal commands with a permission system for safety.

How It Works

Commands from your browser reach the agent via Firebase Realtime Database WebSocket — instant delivery, zero polling. The local AI processes the command, plans a sequence of actions, and executes them on your PC.

Self-Improvement

Self-Improving Skills

Every successful task gets analyzed. When a repeatable pattern is detected, a skill file is saved to ~/.vnus-agent/skills/. Next time you ask for the same task, the skill runs directly — no AI planning step, no wait. 10x faster.

  • 1
    First time — AI plans and executes
    Command is processed by AI. Successful execution saved as a pattern candidate.
  • 2
    Skill detected and saved
    After repeated success, a skill file is created with trigger phrases, action templates, and success counter.
  • 3
    Future runs are instant
    Matching commands skip AI planning entirely. Skill executes directly. Self-heals if the environment changes.

FAQ

❓Does the agent work without internet?›

Yes. After first setup, all AI processing runs offline. The only network activity is the Realtime Database WebSocket to receive commands from your dashboard — a tiny amount of data. The AI model itself runs entirely on your hardware.

❓Where does my data go?›

Commands temporarily pass through Realtime Database to bridge your browser and PC. AI processing happens entirely on your machine. Memory, skills, session history, tokens, and API keys are stored locally — never transmitted to any server.

❓Can I use the agent on multiple PCs?›

Yes. Each PC gets its own permanent connection code. Add as many workspaces as your plan allows. Each workspace has its own model, memory, and skills — they do not share data with each other.

❓Does the scheduler run when my browser is closed?›

Yes. The scheduler runs inside the Electron app in your system tray. As long as the tray icon is visible, all scheduled tasks run on time regardless of whether the dashboard is open in a browser.

❓How long does Business DNA setup take?›

About 5 minutes. The agent asks 20 questions one at a time. After that it never asks again — all context is permanent until you update it.

❓Do I need to connect an API key?›

No. The agent works entirely on local AI without any API key. An API key unlocks higher quality output for complex tasks. Simple tasks — file operations, browser automation, apps — always use local AI regardless of whether an API key is connected.

❓What if the model download fails?›

The agent shows a specific error message and a Retry button. Your plan stays active. Check your internet connection and ensure you have at least 2 GB more free disk space than the model size.

Architecture

brain.js — Intelligence layer

Builds the system prompt from persistent memory, learned skills, business DNA context, and task-specific Chain-of-Thought instructions. Detects task type — coding, browser, files, reasoning — and routes to the best available model. Responses are parsed as structured JSON action sequences. Invalid output retries up to 3 times automatically. When an API connector is connected, complex tasks route through it before falling back to local Ollama.

listener.js — Command delivery

Firebase Realtime Database SSE WebSocket — zero polling, instant delivery. Rate limited to 20 commands per minute per user. Ownership verified before every execution. Handles connector actions, screenshot requests, and proactive scheduler startup. Heartbeat every 30 seconds to keep workspace status current.

businessDNA.js — Business context

20-question setup flow stored at ~/.vnus-agent/business-dna.json. Injects business context into every AI prompt. Powers role-based agent modes (CEO, CMO, CTO, CFO, Sales). Source of context for all proactive features.

multiAgent.js — Team system

Boss Agent detects complex tasks using pattern matching and selects the best team template. 8 specialized agents each with a distinct system prompt. Sequential execution with context passing between agents. Results compiled by the Editor Agent. Team sessions saved to ~/.vnus-agent/teams/.

proactiveAgent.js — Proactive intelligence

Generates morning briefings at 9 AM, opportunity scans every 6 hours, and weekly reports on Monday mornings. All results synced to RTDB for display in the dashboard. Requires Business DNA to be set up first.

scheduler.js — Cron engine

node-cron engine registers all 6 trigger types on startup. Create, update, delete, and run-now operations received via RTDB WebSocket instantly from the website. History logged to ~/.vnus-agent/schedule-history.json. Retry with exponential backoff on failure.

connectors.js — API connector layer

Stores API keys encrypted at ~/.vnus-agent/connectors.json using AES-256-CBC with your machine ID as the encryption key. Keys are never sent to RTDB — only a masked version syncs to the dashboard. Supports 10 providers with OpenAI-compatible and provider-specific API formats.

memory.js — Learning layer

Reads and writes ~/.vnus-agent/memory.json. Preferences, facts, corrections, and session summaries injected into every AI prompt. Extracts learnings automatically from completed tasks.

skills.js — Skill engine

After each successful task, checks if the command matches a learnable pattern. Saves skill files locally with trigger phrases, action templates, and success counter. Failed skills marked stale and regenerated from fresh AI planning.
