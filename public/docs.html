Architecture

How It Works

Agentic Vnus runs as a desktop application on your PC. When you type a command on the website, it's relayed to your PC through a secure real-time channel. A local AI model reads the command, plans a sequence of actions, and executes them on your machine.

Request Flow

You type a command
→
Secure cloud relay
→
Desktop agent (polls every 3s)
→
Local AI model
→
Actions on your PC
→
Result back to you

Critical Rule

The 50% RAM Rule

This Rule Always Applies — No Exceptions

The AI model must use no more than 50% of your total RAM. This keeps your PC running smoothly while the agent works. The app enforces this automatically — you cannot override it.

Your plan unlocks which models exist — but your RAM determines which ones actually run. A Pro plan user on 8GB RAM gets the same model as a Free plan user on 8GB RAM.

Self-Improvement

Self-Improving Skills

Every time you complete a task successfully, the agent analyzes the pattern. If it detects something repeatable, it saves a skill file. Next time you ask for the same type of task, the skill runs directly — no AI planning step needed, which makes it instant.

  • 1
    Task completed successfully
    Example: "Open Chrome and search for Python tutorials" — browser opens, navigates, searches.
  • 2
    Pattern detected
    Agent checks whether this matches a known pattern — browser task, email, file creation, code repository operation.
  • 3
    Skill file saved
    A skill is stored locally with trigger phrases, action steps, and a success counter.
  • 4
    Future tasks run faster
    Matching commands use the proven skill pattern instead of asking the AI to re-plan from scratch. Skills also self-heal — if a website changes its layout, the skill detects the failure and re-learns automatically.

Security

Security Model

Agentic Vnus is built with a defense-in-depth approach. Multiple independent layers protect you from both malicious commands and AI mistakes.

LayerWhat It Does
Permanent BlocklistCertain commands are permanently blocked and can never be executed, regardless of who sends them — disk format, recursive deletion of system paths, fork bombs.
Permission SystemHigh-risk and medium-risk commands pause and show an Approve/Deny banner in your workspace. The agent waits up to 60 seconds for your decision before timing out.
Rate LimitingMaximum 20 commands per user per minute. Excess commands are rejected automatically, protecting your PC from being overwhelmed.
Ownership VerificationEvery command is verified against the workspace owner's identity before execution. Commands from mismatched accounts are silently rejected.
Secure Access RulesAll data — commands, chats, permissions, screenshots — is access-controlled. Only the authenticated workspace owner can read or write any of it.
JSON Retry LoopIf the AI produces a malformed response (a common issue with smaller models), the agent retries up to 3 times with clearer instructions before failing safely.

Important

Warnings & Limitations

Small Models Make Mistakes

On 8 GB RAM, the agent uses a 4B parameter model. It handles simple tasks well but may misunderstand complex multi-step commands, produce incorrect file paths, or choose wrong interface elements. If a command fails, rephrase it more specifically and retry.

No Undo for Destructive Actions

The agent can delete files and push code changes. There is no confirmation step for low-risk operations. Always verify the intent of your command before sending it. Blocked commands prevent the most dangerous operations automatically.

Internet Required for Initial Setup

The AI engine and model must be downloaded on first use. After that, the agent works fully offline. On slow connections, a 19 GB model can take over an hour to download.

PC Performance During Inference

When the AI processes a command, it uses significant CPU and RAM. Your PC may feel slower for 5–30 seconds per command. The 50% RAM rule reduces this impact but does not eliminate it.

CAPTCHA Cannot Be Bypassed

Websites that show CAPTCHA challenges during automation will block the agent. This includes some financial institutions, government portals, and heavily protected login pages. You will need to complete these manually.

Email Requires Browser Login

Email sending works through browser automation — the agent opens Gmail or Outlook and uses the compose interface. Direct email sending without a browser is not yet supported and is planned for a future update.

FAQ

Frequently Asked Questions

Does the agent work without internet?

Yes — after the first setup, everything runs offline. The only network activity is the 3-second polling to check for new commands from your dashboard, which is a tiny amount of data.

Where does my data go?

Commands are temporarily stored in a secure cloud relay to bridge your browser and your PC. AI processing happens entirely on your machine. Memory, skills, session history, and access tokens are stored locally and never transmitted anywhere.

How do I reconnect after disconnect?

Open the agent app — it shows your connection code. Go to your dashboard → Add Workspace → enter the code. Your permanent code never changes on the same machine.

How do I delete a downloaded model?

Open Terminal or Command Prompt and run: ollama rm [model-name]. Then reopen the agent — the model picker will appear so you can download a different one.

Can I use the agent on multiple PCs?

Yes — each PC gets its own connection code. Add as many workspaces as your plan allows. Each workspace runs independently with its own model and memory.

What if the model download fails?

The agent shows a specific error message and a Retry button. Your plan stays active — retry after checking your internet connection and available disk space. You need at least 2 GB more free space than the model size.

Does the agent run in the background?

Yes — it stays in the system tray while running. Commands sent from the dashboard are executed as long as the tray icon is visible. Right-click the tray icon → Quit to stop it.

Technical Reference

Architecture Deep Dive

For developers and technically curious users who want to understand how the agent works internally.

Intelligence Layer

The core intelligence module builds a system prompt that combines your persistent memory, available skills, and task-specific reasoning instructions. It detects whether a command is a coding task, browser task, file operation, or reasoning question — and adjusts both the prompt structure and the AI model selection accordingly. Responses are parsed as structured action sequences. If the AI produces malformed output, the module retries with increasingly explicit formatting instructions.

Memory Layer

Reads from and writes to a local JSON file on startup and after every task. User preferences, saved facts, corrections, and session summaries are all stored here. The entire memory context is injected into every AI prompt, so the agent always has full context without you repeating yourself.

Skills Layer

After each successful task, the system checks whether the command matches a learnable pattern. If it does, a skill file is saved locally. Skills include trigger phrases, action templates, and a success counter. Skills that fail are automatically marked stale and regenerated from fresh AI planning on the next use.

Command Listener

Polls the cloud relay every 3 seconds for pending commands. Uses a local set to track in-progress commands and prevent double execution. Verifies command ownership before executing. Enforces a rate limit of 20 commands per minute per user. All execution happens asynchronously — the poll loop never blocks.

Action Execution Priority

1. Browser actions   — most reliable for web tasks
2. PC control        — native app interactions
3. File operations   — always reliable
4. Repository API    — requires access token
5. Shell commands    — most powerful, permission-gated
Shell Commands Are Powerful

Shell command execution runs with the permissions of the current user. Dangerous patterns are blocklisted, and medium/high risk commands require explicit approval. Use shell commands only when you understand what will run.
